# LeonardX glossary

- **Latency:** time for one request; p95 means 95% complete within that value.
- **Throughput:** completed requests/jobs per unit time.
- **Concurrency:** work active at the same time.
- **Queue:** durable waiting records for asynchronous work.
- **Worker:** process that claims and completes queued work.
- **Idempotency:** repeating an event produces one state transition.
- **RLS:** Postgres row-level policies that restrict visible rows.
- **SLO/SLI:** target and measurement for reliability.
- **RTO/RPO:** recovery time and acceptable data-loss windows.
- **Backpressure:** slowing admission when downstream capacity is full.
