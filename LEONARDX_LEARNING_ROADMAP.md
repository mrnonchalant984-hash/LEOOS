# LeonardX learning roadmap

1. Foundations: Next.js routes, TypeScript, Supabase auth/RLS and migrations.
2. Security: API keys, tenant checks, SSRF, HMAC and secret handling.
3. Operations: tests, Vercel releases, Sentry, health checks and incidents.
4. Reliability: queues, idempotency, retries, load testing and backups.
5. Scale: query plans, multi-instance limits, AI budgets and cost modeling.

Completion means running the matching safe exercise and recording evidence, not merely reading the document.
