# LeonardX observability tutorial

Sentry sanitization is centralized in [`lib/monitoring-utils.ts`](./lib/monitoring-utils.ts). Browser telemetry is mounted by [`app/observability-scripts.tsx`](./app/observability-scripts.tsx). `/api/health` is liveness only. Configure provider alerts manually, then validate a controlled staging error without prompts, tokens or payment data.
