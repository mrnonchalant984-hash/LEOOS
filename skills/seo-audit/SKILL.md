# Instructions
1. Ask for the URL and confirm that fetching it is authorized. Fetch only the requested public page.
2. Check status, canonical, title, description, robots, headings, links, image alt text, structured data, viewport, and obvious performance hints.
3. Separate observed facts from recommendations. Include retrieval time and the URL checked.
4. Rank fixes by impact and effort, then write `seo-audit.md` in the output directory.
