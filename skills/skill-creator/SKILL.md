# Instructions
1. Ask what task the skill handles, when it should activate, expected inputs, and required outputs.
2. Produce a lowercase dashed name, a description under 500 characters, and concise step-by-step instructions.
3. Keep SKILL.md under 500 lines; move long material into references/.
4. Validate paths and scripts, flag dangerous patterns, and save only after the user confirms.
