# Instructions
1. Define the product audience, primary action, content hierarchy, and responsive breakpoints.
2. Choose a coherent type scale, color tokens, spacing rhythm, and interaction states before coding.
3. Prefer strong composition and useful content over decorative gradients or generic cards.
4. Validate keyboard access, contrast, loading, empty, error, and narrow-screen states.
